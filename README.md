# Bayora Security Lab

Build a modern, polished dark/light mode AI security & red-teaming dashboard called 'Bayora' using Next.js, Tailwind CSS, and Shadcn UI components. Include:

Top navigation with Bayora branding, light/dark theme switcher, and sign-in buttons for Google and GitHub.

Red-Team Test Campaign section with adversarial prompt input and model evaluation trigger button.

Blue-Team Guardrail Configuration panel with toggle switches for safety rules.

Side-by-side comparison view comparing baseline test failures vs defended re-test outputs.

A cryptographic audit log table displaying timestamped SHA-256 hashes with tamper verification status badges.
